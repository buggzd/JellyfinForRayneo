# Jellyfin 功能路线图

本路线图以 Jellyfin Web 的信息架构为基准，并针对 RayNeo Air 的远距显示、射线指向和手机输入场景做取舍。眼镜端负责浏览与播放；服务器地址、账号、密码及复杂文字输入继续放在手机端。

## 当前里程碑：详情、用户状态与播放降级

- 自适应纵向详情页：海报、背景、标题、原始标题、简介和可拖拽内容区。
- 元数据：分级、评分、类型、标签、导演、演员、工作室、制作地区、首映日期、状态和外部 ID。
- 媒体规格：分辨率、编码、HDR/SDR、帧率、码率、音频、字幕和播放能力。
- 用户数据：继续播放、收藏切换、已观看切换并同步 Jellyfin。
- Jellyfin 简介中的 HTML 标签和实体转换为可读纯文本。
- Android 系统硬解、LibVLC MediaCodec 兼容容器硬件优先、本地软件解码、Jellyfin H.264/AAC 转码自动降级。
- 音轨选择；文字字幕本地渲染，位图字幕服务端烧录。

## P1：发现内容

- 全局搜索，并在手机端提供文字输入，在眼镜端显示结果。
- 详情页增加“相似内容”“更多来自该系列”和演职人员横向卡片。
- 媒体库完整浏览、类型/年份/评分筛选、排序和收藏列表。
- 首页继续观看、下一集和最新内容支持分页加载。

## P2：剧集与播放队列

- 季选择、缺失集提示、特别篇以及单集上下集导航。
- 自动播放下一集、随机播放、播放队列和队列编辑。
- 播放结束、手动停止和跨设备续播状态一致性验证。

## P3：高级播放增强

- 播放前选择媒体版本与画质上限；继续完善超多轨道的滚动菜单。
- 字幕样式、延迟调节、章节、缩略图进度条和跳过片头能力。
- 向用户暴露更完整的 Direct Play、软件解码和 Transcode 失败原因。

## P4：账户与设备体验

- 多服务器和多用户切换、快速重连及会话失效处理。
- 手机端作为伴侣控制器：键盘输入、队列管理和播放控制。
- RayNeo 真机上的焦点、射线、长按、返回键和双显示端生命周期测试。

每个阶段都需要 EditMode、PlayMode 和 RayNeo 真机验证；UI 变更应附 Game View 与真机截图。测试数据不得包含局域网地址、令牌或真实凭据。
