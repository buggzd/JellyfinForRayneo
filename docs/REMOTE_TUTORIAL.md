# 眼镜端互动遥控教学

教学使用固定视角的练习空间：左侧展示动作、拇指 SVG 动画和反馈，右侧展示可操控的光点、目标及练习卡片。用户始终看眼镜，在手机触控板上操作。大约一分钟完成六个动作，没有倒计时或失败惩罚。

| 步骤 | 真实遥控输入 | 练习结果 |
| --- | --- | --- |
| 1–4 | 右、下、左、上滑动 | 光点沿四个目标移动，返回中心并解锁卡片 |
| 5 | 单击 | 打开虚构的「蓝色之外」详情卡片 |
| 6 | 快速双击 | 回到卡片列表，显示完成页 |

只有对应输入才能通过当前步骤。操作错误时，画面提示已收到的动作和预期动作。正确后保留 1.1 秒反馈，在这段时间内消耗连续输入，避免一个动作触发两关。方向指令来自既有的手机触控板识别，不另行实现第二套手势阈值。

首次媒体库就绪时显示欢迎页；支持稍后再学、双击暂停、退出以及侧栏重练。完成时保存 `lucent.remote-tutorial.v1=completed`，跳过时保存 `skipped`。本地存储不可用时仍能结束教学并继续浏览。重练从第一步开始，返回后恢复侧栏入口焦点；会话失效会卸载教学。

教学沿用唯一 WebView 的 2D/SBS 输出。场景只是 DOM 和 SVG，不创建播放器，不调用 Jellyfin 播放接口，不保存账号数据。提供减少动态效果时的静态接触姿态，避免依赖动画才能理解操作。

## SVG 来源与修改

使用用户提供的 `thumb-gestures-svg.zip` 中六个带提示的手势 SVG，以及 `reference-default.svg`。只读取矢量内容，没有执行压缩包中的生成脚本。

- 欢迎页人物去掉白底、裁去多余留白。
- 六个练习动画提取 `phone-and-hand`，移除人物场景中的定位矩阵，使用独立的手机/手部视口并补齐袖口。
- 保留原始 3.2 秒 SMIL 路径动画、方向提示和点击波纹。
- 从接触时刻导出六份无动画的静态 SVG，供 `prefers-reduced-motion` 使用。
- 通过 `<img>` 加载单个动作，避免内联 SVG 的 ID 冲突。资源没有外部引用、脚本或栅格图片。

如需从同一素材包重新生成：

```bash
python3 GlassesUI/scripts/prepare-tutorial-gestures.py /path/to/thumb-gestures-svg.zip
```

输出在 `GlassesUI/public/assets/tutorial/`；前端构建会复制到 Android 的本地资源目录。

## 验证

`npm --prefix GlassesUI test` 包括教学状态测试：六步门槛、错误输入、连续输入、暂停/恢复、退出、重练、键盘映射和存储失败。

浏览器回归使用虚构会话和空媒体库，按 Android 的「远程通知 + 冒泡键盘事件」双事件方式发送命令，检查单次推进、唯一焦点、首次显示、显示模式 bootstrap 不重置步骤、完成记忆、退出后恢复焦点以及登出清理。独立预览入口为 Vite 的 `/?tutorial`，生产包不包含该入口。

真机验收必须另行执行 [架构回归矩阵](ANDROID_ARCHITECTURE.md#device-regression-matrix)，尤其是手机手势、减少动态效果、双眼清晰度和显示切换期间的连续性。浏览器验证不能替代这些光学与设备检查。
