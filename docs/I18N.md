# 界面语言与词条维护

手机和眼镜支持简体中文与 English。默认跟随系统：中文地区使用简体中文，其他语言回退到英语。手机连接页在登录前即可选择语言；登录后可在手机或眼镜设置中修改。修改立即同步，不重建 WebView、不切换账号、不刷新媒体库，也不重新准备视频。

Android 在原有 `jellyfin_companion` 偏好文件中增加 `ui_language`，只接受 `system`、`zh-CN`、`en`。退出账号不清除此偏好，恢复默认偏好会恢复 `system`。原有 application ID、会话、主题、字幕和桥接标识保持兼容。系统语言变化通过配置回调重新发布 `systemLanguage`，不重建 Activity；原生 Toast 和系统选择器使用指定语言的资源上下文。启动器名称仍按系统资源语言显示。

## 添加文案

- 共用入口：`SharedUI/i18n.mjs`，英语词条：`SharedUI/locales/en.json`，类型声明：`SharedUI/i18n.d.mts`。
- 中文源文案是稳定的词条键，`t('设置')` 根据当前语言返回文本；缺失的英语词条回退到中文。新增或改动源文案时，同时更新英语词条。词条检查会阻止缺少翻译或占位符不一致的提交。
- 动态内容使用完整消息和占位符，例如 `t('当前用户 {0}', { 0: userName })`。参数以普通文本插值，由 React 转义，不执行 HTML，也不再次翻译参数。
- 服务器提供的标题、简介、人员姓名、轨道名称及字幕内容保持原文。只翻译应用生成的标签、时长、操作和固定提示。语言选择不会修改 Jellyfin 的媒体元数据语言或字幕偏好。
- 业务枚举、排序值、React key、CSS/焦点选择器不得依赖译文。现有中文枚举保持兼容，在显示位置调用 `t`；焦点使用稳定 class/data 标记。
- 模块级静态标签或缓存的应用生成标签须延迟翻译。媒体映射的字幕摘要和时长使用 getter，观看进度更新需保留这些 getter，避免切换语言后显示旧文案。
- 原生仍发布安全、固定的诊断源文案；`nativeMessage` 只对已知词条及两种带数字的固定消息进行转换，不解析任意服务器错误。原生系统 UI 文案维护在 `values/strings.xml` 和 `values-zh/strings.xml`，通过 `UiStrings` 选择语言。

## 状态与预览

`selectLanguage` / `set_language` 通过现有消息桥提交，Android 校验、保存，再同时回传 `language` 与 `systemLanguage`。前端等待回传确认。React 通过外部语言订阅更新现有组件，不以语言作为组件 key。语言变化保留 `catalogGeneration` 和会话身份。

独立网页预览仅使用 `tachi-preview-language` 保存语言；DevHarness 模拟原生两端同步。原生运行不响应浏览器预览存储事件。浏览器偏好不包含账号或会话数据。

## 验证

运行 `./scripts/build-android.sh debug` 和 `node --test DevHarness/harness.test.mjs`。前端覆盖词条、占位符、语言回退、原生确认、元数据原文和观看进度保留；JVM 覆盖白名单、重启及退出账号后的持久化。

无服务器的视觉入口：启动 GlassesUI 开发服务，打开 `/tests/i18n-preview.html`，检查真实设置和遥控教学组件的中英切换、两种主题及长文本。手机可用 production preview 的演示账号检查登录与设置。

桌面检查不能代替 [设备回归矩阵](ANDROID_ARCHITECTURE.md#device-regression-matrix)：需在真机上检查系统语言变化、冷启动、两端编辑、退出账号、renderer 恢复，以及 Direct/HLS 播放中的 2D/SBS 语言切换，确保仍只有一个 WebView、video、声音和进度上报流。
