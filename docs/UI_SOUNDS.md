# 眼镜端 UI 音效

音源来自用户提供的 MORI 音效包，保留原始 48 kHz、16-bit PCM 立体声 WAV
及相对响度。文件位于 `GlassesUI/public/assets/sounds/`，随眼镜端 production
bundle 打包，运行时无需网络下载。手机前端不加载这些文件。

| 音效 | 交互 |
| --- | --- |
| focus / boundary | 遥控焦点实际移动 / 浏览导航无法继续移动 |
| select / back / home | 确认、播放控制 / 返回 / 首页按钮 |
| open / close | 打开媒体卡片、设置、教学或音轨/字幕面板 / 关闭面板 |
| toggle-on / toggle-off | 视频信息开关；重新开启 UI 音效时使用 toggle-on |
| volume | 非零系统媒体音量的遥控调节，最长每 120 ms 一声 |
| success / error / notification | 操作结果 Toast 与教学反馈 |
| loading | 点击侧栏刷新媒体库，一次提示，不循环 |
| wake / sleep | 保留原始素材，当前没有对应的电视电源交互，不触发 |

「设置 → UI 音效」默认开启，关闭动作立即静音，不播放关闭尾音。
关闭开关只影响 UI 提示；影片音轨、音量、字幕和播放上报不变。偏好保存在
眼镜网页本地存储中，不随账号切换、退出登录或 WebView 重建重置。

播放器页面内不播放焦点、确认、返回、面板、开关、边界或错误等 UI 音效，
避免干扰影片声音；只有调节系统媒体音量时保留 `volume` 提示音。

音效池最多保留 14 个可用片段，同一时刻只播放一个，新的操作替换旧的提示。
同一种声音有 70 ms 防抖，音量为 120 ms。焦点停在顶部或其他边界时，连续的
同方向输入只提示一次；焦点移动、方向改变或重新进入该边界后才会再次提示。自动恢复焦点、
自动加载和前后台切换不发声。网页隐藏、销毁或关闭音效会中止活动片段；
资源或自动播放失败不会阻塞操作，也不会积压并延迟重放。

验证需同时覆盖浏览器与 `ANDROID_ARCHITECTURE.md` 的设备回归矩阵，特别是
Android 本地资源播放、耳机/眼镜实际输出、直接播放及 HLS 期间的 UI 提示，
以及 Mirror 2D / SBS 切换时没有重复声音。
