# 塔奇TACHI 应用图标

`source.png` 为用户提供的 571 × 568 原始图稿，保留蓝色机甲、侧面镜头与
银白面板上三枚传感器的特写构图。保存时重新编码 PNG，去除原始元信息。
`preview.png` 显示圆角、圆形及 Android 13 主题图标的裁切效果和 48 像素小图。

使用 Python 3 和 Pillow 重新生成资源：

```bash
python3 scripts/prepare-app-icon.py
```

脚本裁出 536 × 536 图稿，去除外围展示留白，仅在原有圆角之外用相邻图像
补齐四角。彩色前景保持不透明，不叠加底色或光效；由 Android 启动器决定
最终外轮廓。适配图层按 108 dp 输出，特写位于中央 72 dp，四边各延展 18 dp
的边缘像素作为系统动效出血，镜头与三枚传感器保留在中央 66 dp 安全圆内。
单色版沿原图描出银白面板、三个孔、镜头环和上盖边线，供 Android 13 起
支持主题图标的启动器着色。照片渐变不参与单色层，避免着色后细节混成一片。

生成的 mdpi–xxxhdpi PNG 由 Manifest 的自适应图标引用。项目最低版本为 API 26，
统一使用 `mipmap-anydpi` 配置；Android 13 起读取其中的单色层，旧版忽略该层。
密度资源随源码提交；原图和预览不进入 APK。更换原图时需同步检查脚本的裁切
坐标和单色提取范围，确认圆形、圆角及小尺寸下的标记完整。
